    Connect to GitHub (one time)

    The site saves jobs to your aplio repo through GitHub. It needs a key that can only create and update issues in that one repo. The key is stored only in this browser.

    1. Open GitHub → New fine-grained token.
    2. Name it aplio; set an expiry (e.g. 1 year).
    3. Repository access: Only select repositories → aplio.
    4. Permissions → Repository → Issues: Read and write. Nothing else.
    5. Generate, copy, and paste it below.
